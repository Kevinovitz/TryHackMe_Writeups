### Task 1 - Hacker Holidays: Day 2

1.  What is the flag?

    Lets start with a simple `nmap` scan.

    ```console
    nmap -sV  -sC 10.113.135.63  
    ```

    ![Nmap](https://github.com/Kevinovitz/TryHackMe_Writeups/raw/main/hh-room404-804573bf/Room_404_Nmap.png)

    We can see an http server and ssh service running. The http server script also returned an interesting artifact.

    Lets view the page in our browser. 

    ![Homepage](https://github.com/Kevinovitz/TryHackMe_Writeups/raw/main/hh-room404-804573bf/Room_404_Homepage.png)

    There is not much here and none of the links seems to lead anywhere. Not even the booking button.

    ![404](https://github.com/Kevinovitz/TryHackMe_Writeups/raw/main/hh-room404-804573bf/Room_404_404.png)

    Lets use `gobuster` to find any hidden directories as it states in the challenge that the hidden rooms are worth investigating.

    ```console
    gobuster dir -u http://10.113.135.63:8080 -w /usr/share/wordlists/SecLists/Discovery/Web-Content/common.txt  -t 20
    ```

    ![Gobuster](https://github.com/Kevinovitz/TryHackMe_Writeups/raw/main/hh-room404-804573bf/Room_404_Gobuster.png)

    Looks like we have a Github repo directory! This was also revealed in the nmap scan. Lets investigate this.

    ![Git](https://github.com/Kevinovitz/TryHackMe_Writeups/raw/main/hh-room404-804573bf/Room_404_Git.png)

    There are a lot of files and we should download them to make it easier.

    ```console
    wget -r -np -nH -R "index.html*" http://10.113.135.63:8080/.git/
    ```

    ![Wget](https://github.com/Kevinovitz/TryHackMe_Writeups/raw/main/hh-room404-804573bf/Room_404_Wget.png)

    Now that we have all the files we can do some digging. Looking around I couldn't find any promising files nor did I find any traces of flags inside the files.

    After some searching I found out I had to use `git` to actually look at the files within the repo. That actually helped.

    ```console
    git checkout
    git checkout README.md
    cat README.md
    ```
